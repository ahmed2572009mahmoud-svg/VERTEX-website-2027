# سوشيال بوست - SMM Panel

## التشغيل المحلي
pip install -r requirements.txt
ADMIN_PASSWORD=غيّرني_دلوقتي python app.py      # http://localhost:5000

أول مرة بيتعمل حساب أدمن (admin). لو ما حطيتش ADMIN_PASSWORD هيطبع باسورد عشوائي في الشاشة.

## التشغيل على سيرفر
gunicorn -w 2 -b 0.0.0.0:8000 app:app
حط الموقع ورا HTTPS (Nginx/Cloudflare) وشغّل COOKIE_SECURE=1.

## الإعداد من لوحة الأدمن (/admin)
1. الإعدادات: اسم الموقع، أرقام فودافون كاش/إنستاباي، رابط ومفتاح API بتاع المزوّد.
2. الخدمات > استيراد: يجيب خدمات المزوّد ويضيف نسبة ربحك وسعر الصرف.
3. شحن الرصيد: العميل يحوّل ويبعت رقم العملية، وإنت توافق من "طلبات الشحن".
4. الطلبات: بتتبعت للمزوّد تلقائي. تحديث الحالات: زر المزامنة أو cron:
   */5 * * * * cd /path && flask --app app sync-orders

## مهم
- غيّر أرقام الدفع الوهمية في الإعدادات قبل الإطلاق.
- المتابعين المدفوعين بيخالفوا شروط المنصات؛ وضّح ده للعملاء ولا تطلب كلمات مرور حساباتهم.
